# Text Classification using Multinomial Naive Bayes

This project classifies documents from the scikit-learn 20 Newsgroups dataset using TF-IDF and Multinomial Naive Bayes.

## Files
- `train.py`: Model training script.
- `predict.py`: Model inference script.
- `20newsgroups_model.joblib`: Exported model artifact.
- `requirements.txt`: Package dependencies.
